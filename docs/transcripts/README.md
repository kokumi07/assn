# 실제 터미널 실행 기록

`python tools/capture_examples.py`가 수정하지 않은 `assn1.py`의 `play_game()`을 별도 Python 프로세스와 실제 PTY에서 실행한 결과다. PTY가 사용자 입력을 한 번씩 화면에 되비추며, 저장 시 CRLF만 LF로 정규화한다.

재현 가능한 보고서 예시를 얻기 위해 테스트 실행 중에만 `unittest.mock.patch('random.randint', side_effect=...)`로 컴퓨터 선택을 아래 순서에 고정했다. 일반 실행(`python assn1.py`)에서는 이 패치를 사용하지 않으며, 컴퓨터가 매 라운드 무작위로 1~3을 선택한다. 따라서 동일 입력의 일반 실행 결과가 아래 기록과 같다고 보장하지 않는다.

| 기록 | 컴퓨터 선택 순서 | 검증 내용 |
| --- | --- | --- |
| validation.txt | 없음 | 계단 수 3·123 거부 후 5 허용 |
| mixed.txt | 3, 2, 2 | 플레이어 승리·컴퓨터 승리·무승부 |
| player_win.txt | 2, 2 | 플레이어 5→2→0, 초과 이동 보정 |
| computer_win.txt | 2, 2, 3 | 컴퓨터 5→3→1→0, 초과 이동 보정 |
| quit.txt | 없음 | NO 취소, 재확인, 오타 거부, YES 종료 |

각 실행은 자식 프로세스 종료 코드 0과 최종 메시지·위치를 확인한다. 프로그램 자체에는 외부 패키지가 필요 없고, 이 문서용 캡처 도구만 `pexpect`를 사용한다.
